# Signal Catalog

Generated from `src/trader/provider/signals.py`; do not edit this file by hand.

This catalog is scoped to the technical signals supported by stored market bars under
`architecture.md` section 8. Calendar and event signals land in a later provider task
and regenerate this same file.

| signal | units | description |
| --- | --- | --- |
| `minutes_since_open` | minutes | minutes elapsed from the regular-session open to this bar |
| `minutes_to_close` | minutes | minutes remaining from this bar to the regular-session close (the actual close, so early-close days compress correctly) |
| `price` | USD | SNDK price at this bar's close |
| `vwap` | USD | session volume-weighted average price so far today, regular hours only, from typical price (high+low+close)/3 |
| `vwap_sigma` | USD | standard deviation of close-minus-VWAP over the session so far; reads 0.0 until more than 5 bars exist |
| `vwap_z` | sigma | how far the current close sits from VWAP, in session-sigma units; 0.0 while vwap_sigma is 0 |
| `vwap_dist_pct` | percent | unsigned distance from VWAP as a percent of VWAP -- how far 'away from fair' price is right now, ignoring which side. Reads 0.0 when VWAP itself is 0 |
| `vwap_side_run_minutes` | bars | how long price has stayed on one side of VWAP -- positive above, negative below. Counts BARS, so a session with missing interior minutes undercounts the true elapsed time |
| `or5_high` | USD | highest high of the first 5 regular-hours bars of the session; reads 0.0 until 5 bars exist |
| `or5_low` | USD | lowest low of the first 5 regular-hours bars of the session; reads 0.0 until 5 bars exist |
| `or5_range` | USD | high-to-low span of the first 5 regular-hours bars; reads 0.0 until 5 bars exist, which is indistinguishable from a genuinely zero-width range |
| `or15_high` | USD | highest high of the first 15 regular-hours bars of the session; reads 0.0 until 15 bars exist |
| `or15_low` | USD | lowest low of the first 15 regular-hours bars of the session; reads 0.0 until 15 bars exist |
| `or15_range` | USD | high-to-low span of the first 15 regular-hours bars; reads 0.0 until 15 bars exist, which is indistinguishable from a genuinely zero-width range |
| `or60_high` | USD | highest high of the first 60 regular-hours bars of the session; reads 0.0 until 60 bars exist |
| `or60_low` | USD | lowest low of the first 60 regular-hours bars of the session; reads 0.0 until 60 bars exist |
| `or60_range` | USD | high-to-low span of the first 60 regular-hours bars; reads 0.0 until 60 bars exist, which is indistinguishable from a genuinely zero-width range |
| `day_high` | USD | highest high of the regular session so far |
| `day_low` | USD | lowest low of the regular session so far |
| `new_day_high` | boolean (0/1) | 1.0 when THIS bar's high is the session's running high |
| `new_day_low` | boolean (0/1) | 1.0 when THIS bar's low is the session's running low |
| `day_range_atr` | multiples of daily ATR | session high-to-low range so far, measured in daily-ATR units |
| `gap_pct` | percent | opening gap: the regular-hours open against the prior session's close |
| `open_vs_prior_high` | USD | regular-hours open minus the prior session's high; positive means the session opened above yesterday's range |
| `open_vs_prior_low` | USD | regular-hours open minus the prior session's low; negative means the session opened below yesterday's range |
| `price_vs_prior_high` | USD | current price minus the prior session's high |
| `price_vs_prior_low` | USD | current price minus the prior session's low |
| `first_bar_ret` | percent | the FIRST regular-hours bar's own return, its close against its open. Positive means the session's opening minute printed up. Exactly 0.0 is a genuinely directionless first bar, not a missing reading -- the first bar exists from the first feature computation onward. Named so 'break the opening range in the direction of the first bar' can be stated as a condition over a signal rather than arithmetic buried in one algo |
| `ret_from_open` | percent | return from the regular-hours open to the current price |
| `day_ret_from_prev_close` | percent | return from the prior session's close to the current price |
| `first30_ret` | percent | return from the prior session's close to the 30th regular-hours bar's close; reads 0.0 until 30 bars exist |
| `rvol_open_30m` | multiples of baseline volume | relative volume of the opening window: volume SO FAR this session against the prior-sessions volume baseline for the SAME elapsed window, capped at the first 30 bars. Before 30 bars have elapsed this is an elapsed-window reading (5 minutes vs the baseline's first 5 minutes), NOT a 30-minute one -- see rvol_open_30m_true for the strict version |
| `rvol_open_30m_true` | multiples of baseline volume | the same opening-window relative volume measured over the FULL first 30 regular-hours bars; reads the documented neutral 0.0 until those 30 bars exist, then the true full-window value |
| `rvol_slot` | multiples of baseline volume | this bar's volume against the prior-sessions baseline for the same minute-of-day slot |
| `atr_day` | fraction of price | mean of up to the last 14 consecutive-session true ranges from daily bars, in return units (a fraction of price, not dollars); reads 0.0 when no true-range pair exists |
| `atr_px` | USD | the same daily average true range converted to dollars at the current price (atr_day x price) -- the unit every ATR-sized stop distance and range-size test is measured in |
| `peer_above_vwap_count` | count (0-4) | how many peer symbols (MU, SOXX, SPY, QQQ) are at or above their own session VWAP right now -- exactly at VWAP counts as above. Only peers whose bars were loaded and that have more than 5 bars so far are counted at all, so 0.0 means peers not confirming OR not observed |
| `peer_below_vwap_count` | count (0-4) | how many peer symbols (MU, SOXX, SPY, QQQ) are STRICTLY below their own session VWAP right now. An unloaded or too-short peer is counted on neither side, so the two counts sum to the peers actually observed, not to 4 |
| `comparable_ret_spread` | percentage points | how far SNDK's return-since-open is running AHEAD of its comparable (MU), in percentage points. Positive means SNDK is outperforming the comparable; reads neutral 0.0 when MU is unobserved, so 0.0 means dead level OR no comparison possible |
| `sector_ret_spread` | percentage points | SNDK's return-since-open minus the mean return-since-open of the sector proxy (SOXX), in percentage points. Positive means SNDK is outrunning the semiconductor sector. An unobserved sector reads neutral 0.0, not a flat sector |
| `market_ret_spread` | percentage points | SNDK's return-since-open minus the mean return-since-open of the market proxies (SPY, QQQ), in percentage points. Positive means SNDK is moving on more than the broad tape. Neutral 0.0 when neither market proxy is observed |
| `idio_strength` | percentage points | the part of SNDK's return-since-open that the sector and market are NOT explaining: SNDK's return minus the mean return-since-open pooled across SOXX, SPY, QQQ, equal weight per observed peer. This assumes beta = 1 and is a proxy, not a regression. Neutral 0.0 when no sector or market peer is observed |
| `comparable_agrees` | boolean (0/1) | 1.0 when SNDK and its comparable (MU) are pointing the SAME way since the open -- both up or both down -- and 0.0 otherwise. Exactly flat agrees with nothing. Reads 0.0 when MU is unavailable, so 0.0 means not agreeing OR not observed |
